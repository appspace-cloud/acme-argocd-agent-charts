acme-argocd-agent-charts

Helm charts for the argocd-agent principal and agent components.

This site is the Helm chart repository. The chart index is at index.yaml. It points to the packaged charts: most of them are attached to the GitHub releases, the two oldest ones are served from this site.

Charts

  • argocd-agent-principal — runs on the hub cluster. It receives the connections from the agents.
  • argocd-agent-agent — runs on each spoke cluster. It connects out to the principal.

For the current versions of both charts, see index.yaml.

Add the repository

helm repo add acme-argocd-agent https://appspace-cloud.github.io/acme-argocd-agent-charts
helm repo update
helm search repo acme-argocd-agent

Install the principal (hub cluster)

helm install argocd-agent-principal acme-argocd-agent/argocd-agent-principal \
  --namespace argocd

Install the agent (each spoke cluster)

helm install argocd-agent acme-argocd-agent/argocd-agent-agent \
  --namespace argocd

The principal and the agent must run the same argocd-agent version. The principal rejects an agent on a different version. The two chart versions are not the same number, so check the appVersion of each chart, not the chart version.
